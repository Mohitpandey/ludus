# Ludus v0.3

AI agent chat UI with tool-calling via Ollama + beautiful Fin-style layout.

## Features
- Chat with LLM agent via local model (llama3-groq-tool-use)
- Tools: `generateComponent`, `getWeather`, `chat`
- Clean modern UI
- Markdown + future visual JSX preview support

## Setup
```bash
chmod +x scripts/install.sh
./scripts/install.sh
npx expo start --web
```
